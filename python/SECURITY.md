# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities in this SDK privately:

- Email: support@dymium.io
- Support portal: https://support.dymium.io/hc/en-us/requests/new

When possible, include:

- Affected package and version (for example, `dymium==0.0.1`)
- Reproduction steps or proof of concept
- Expected vs actual behavior
- Potential impact and exploitability

Do not disclose unpatched vulnerabilities in public issues, pull requests, or forums.

## Response Process

The Dymium team will triage reports, confirm impact, and coordinate remediation.
If your report is accepted, we will provide status updates and publish a fix.
